# App icons

Four apps, four icons, one family. The SVGs are the masters; every PNG here
is generated by `render.py` and must never be touched in a bitmap editor.

## What each one is

| file | app | the shape | why |
|---|---|---|---|
| `tofu.svg` | Agedashii Tofu | one tall block with two stacked beside it | The dish plated - agedashi tofu arrives as blocks - and the dashboard layout at the same time: the big surface you live on, and the pieces next to it that became the other three apps. |
| `moto.svg` | Agedashii Moto | a road curving up to an arrow head | Trips are the curve, XNAV is the head, Garage is the bike that got you there. The one diagonal in the family. |
| `watudo.svg` | Agedashii Watudo | an hourglass | A planner for someone tracking pain and spoons is not a list of tasks, it is a budget of something that runs out. Future Finds is the sand still in the top half. |
| `foodzen.svg` | Agedashii Foodzen | a bowl with a pulse over it | The bowl the dish is actually served in, so this is the piece that kept the dish rather than the blocks. The line is steam and a heartbeat at once: sodium, sugar and blood pressure are the same question about what the food does afterwards. |

## Colours

Three, and only three, and they are the brand gradient from `main.py`:

| stop | hex | name in `main.py` |
|---|---|---|
| 0.0 | `#ffb020` | `ORANGE` |
| 0.5 | `#ff5e8a` | `PINK` |
| 1.0 | `#39d0ff` | `CYAN` |

Background: `#0d1117`, flat, full bleed, the same dark reference the app uses.

Every glyph is filled with one instance of that gradient across its own
bounding box, the same way `brand_chip()` paints the product pill. Nothing
is a second colour, nothing is a tint, nothing has a shadow or a bevel.

Gradient direction is horizontal (left to right, as the brand reads) on
Tofu, Watudo and Foodzen. Moto is the exception: its gradient runs along
the route, bottom-left to top-right, because the route is the object and
the object carries the brand.

## The rule about themes

**These icons do not follow the theme and must never be made to.** They sit
on the OS launcher, not inside the app, and the app has 24 themes; an icon
that matched one of them would be wrong on the other 23 and would change
under the user without warning. They use the fixed brand gradient, which is
not a theme colour - `ORANGE`/`PINK`/`CYAN` in `main.py` are constants, not
palette lookups, and `packages/agedashii-qi/agedashii_qi/themes.py` has no
say here.

So: **if a theme changes, do nothing.** If the *brand gradient itself*
changes - the three constants at the top of `main.py` - then edit the three
`<stop>` values in all four SVGs to match and re-run `render.py`. That is
the only change that should ever reach this directory.

## Regenerating the PNGs

```sh
/home/nvii/venvs/flet/bin/python assets/icons/render.py
```

That writes `<id>-1024.png`, `<id>-512.png`, `<id>-192.png` and `<id>-48.png`
for each of the four ids (`tofu`, `moto`, `watudo`, `foodzen`). 1024 is what
`flet build` wants for an app icon; 48 exists because 48 is the size the icon
is actually judged at on a phone home screen.

`render.py` tries `rsvg-convert`, then `inkscape`, then `cairosvg`, and uses
the first one present. On this machine only `cairosvg` is installed (there is
a librsvg shared library but no CLI for it), inside
`/home/nvii/venvs/flet`. If it ever goes missing:

```sh
/home/nvii/venvs/flet/bin/python -m pip install cairosvg
# or, for the faster CLI path:  sudo apt install librsvg2-bin
```

To re-run the silhouette check, which writes greyscale contact sheets to a
temp directory and prints the path:

```sh
/home/nvii/venvs/flet/bin/python assets/icons/render.py --check
```

## Constraints these were drawn against

- No text. No letter, no initial, no wordmark - unreadable at 48px.
- Identifiable from each other at 48px **with the colour removed**. Colour is
  deliberately identical across all four, so silhouette is the only thing
  doing the work: a block layout, a diagonal, an upright pinched shape, and a
  bottom-heavy mass with a mark above it.
- All meaningful artwork sits inside the centre 66% circle (radius 338px on
  the 1024px canvas) so Android's adaptive-icon mask cannot crop anything.
  Measured worst case: Moto at 331.7px.
- Flat and geometric. No shadows, bevels, skeuomorphism or gradient meshes.
- Nothing borrowed. Tofu was originally an even 2x2 of equal squares; at 48px
  that is a very famous four-square logo and nothing else, so the layout was
  made uneven.

## Wiring them up

Nothing outside this directory has been changed. Pointing each app's build at
its icon - `pyproject.toml`, the per-app Flet build config, `.github/` - is the
integrator's call, not this directory's.
